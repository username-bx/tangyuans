pm2

1. 安装
   npm i -g pm2
2. 启动，并记录日志

```sh

pm2 start server.js --name "slot-frontend" --node-args="--max-old-space-size=1536" --max-memory-restart 1800M --output "/home/ec2-user/app/slot-fontend/log/server.log" --error "/home/ec2-user/app/slot-fontend/log/server.log"

```

3. 验证状态

```sh
pm2 status
```
